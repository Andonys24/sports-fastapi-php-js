# Paradigmas de Programación - ISC204
## Backend de tienda de Deportes en Python
En la presente parte se encuentra el backend del proyecto de una tienda de artículos deportivos, el cual está realizado en Python, utilizando FastApi para crear las rutas y esquemas, así como Uvicorn como servidor web para alojar el servicio.
> [!IMPORTANT]
> El puerto utilizado por el servidor web Uvicorn será el puerto 8000
## Clases -> app/models
- Usuario
- Producto
- Categoria
- Proveedor 
- Compra
